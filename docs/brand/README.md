# Logo ANTAREJA

- `logo-asli.png` — berkas logo dari pemilik (225×225, latar putih). Sumber semua turunan.
- Turunan di `web/public/`: `brand/logo.png` (latar transparan, dipotong ke lingkaran), `brand/apple-touch-icon.png` (180 px),
  `brand/favicon-32.png`, `favicon.ico` (16/32/48).

Logo adalah milik perusahaan pemilik ANTAREJA NMS dan **tidak** termasuk lisensi kode sumber. Bila tersedia versi vektor
(SVG/AI) atau resolusi lebih tinggi, ganti `logo-asli.png` lalu buat ulang turunannya agar tampil tajam di layar besar (NOC).
